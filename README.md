# GameFighting

2.5D-файтинг в стиле PS1 на Unreal Engine 5 (в духе Brawlhalla). Бойцы: Пепельный Кающийся, Пустой Король, Багровый Палач.

## Скачать и играть

1. Открой **[Releases → последняя версия](https://github.com/femison/game/releases/latest)** и скачай `GameFighting_Win64.zip`.
2. Распакуй архив в любую папку (не запускай прямо из архива).
3. Запусти `GameFighting\GameFighting.exe`.
   - Если Windows покажет «Windows защитила ваш компьютер» — «Подробнее» → «Выполнить в любом случае».
   - Если не хватает компонентов (VC++ / DirectX) — запусти `Engine\Extras\Redist\en-us\UEPrereqSetup_x64.exe` из папки игры.

Нужны Windows 10/11 (64 бит) и видеокарта с DirectX 12.

## Режимы

- **Тренировка** — против манекена.
- **Двое за одним ПК** — клавиатура + геймпад или два геймпада.
- **Игра по сети 1 на 1** — через локальную сеть, **Radmin VPN** или **Hamachi**:
  1. Оба заходите в одну сеть Radmin VPN / Hamachi.
  2. Хост: «Создать игру по сети» — на экране появится его адрес (Radmin — `26.x.x.x`, Hamachi — `25.x.x.x`).
  3. Друг: «Подключиться по IP» → вводит этот адрес.
  4. При первом запуске разреши игру в брандмауэре Windows (порт 7777 UDP).

## Управление

| Действие | Клавиатура | Геймпад Xbox |

| Ходьба / направление | A / D, W / S | Левый стик |
| Прыжок | Пробел | A |
| Лёгкий / тяжёлый удар | J / K | X / Y |
| Рывок / уворот | Shift | B / LB |
| Блок | L | RB |
| Захват | I или L+J | LT |
| Супер | U или L+K | RT |
| Подсказки | F1 | — |
| Выйти в меню | F10 | Menu (≡) |
